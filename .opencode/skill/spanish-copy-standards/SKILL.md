# Skill: Spanish Copy Standards

Esta skill te entrega las convenciones editoriales para TODO el copy visible al usuario en Solvyx. Aplícala cada vez que escribas o modifiques texto que verá una persona en la app.

## Principios

1. **Español neutro con sesgo mexicano** (es-MX por defecto). Comprensible en LATAM pero cercano a usuarios mexicanos.
2. **Tono cálido, directo, sin moralizar.** Un joven de 18 años debe sentir que le habla un par, no un predicador ni un médico.
3. **Segunda persona del singular** ("tú") por defecto. "Usted" solo si el usuario lo pide.
4. **Sin diminutivos** ("poquito", "ratito", "problemita"). Minimizan lo importante.
5. **Sin mayúsculas enfáticas** para "gritar" ("¡NO!", "¡AUXILIO!"). La forma comunica el énfasis.
6. **Inclusividad de género.** Evitar masculino genérico. Evitar binario forzado.

## Ortografía

### Reglas duras

1. **Tildes correctas siempre.** Revisa con un corrector. Errores comunes:
   - "porque" (conjunción) vs "por qué" (pregunta) vs "porqué" (sustantivo, raro).
   - "más" (cantidad) vs "mas" (adversativo, desuso).
   - "sí" (afirmación) vs "si" (condicional).
   - "tú" (pronombre) vs "tu" (posesivo).
2. **Acento en preguntas:** "¿Por qué?" no "¿Porque?".
3. **No anglicismos innecesarios.** Si existe palabra en español, úsala.
   - "link" → "enlace"
   - "feedback" → "comentario" o "retroalimentación"
   - "scroll" → "desplazamiento"
   - "app" → "aplicación" (excepto que la convención del proyecto sea "app"; en Solvyx sí se usa "app").
4. **"Berto" sin acento en la "o".** No "Bérto".
5. **"Solvyx" sin acento.** Es el nombre del producto.

### Mayúsculas y minúsculas

- **Nombres de marca:** "Solvyx", "Berto", "ASSIST".
- **Sustantivos comunes:** minúscula ("la guía", "el ejercicio").
- **Títulos de pantalla:** oración normal, no Title Case. "Craving muy intenso" no "Craving Muy Intenso".

## Sintaxis

### Claridad ante todo

**Evitar:**
- Oraciones largas (>25 palabras). Dividir.
- Pasivas reflejas sin sujeto claro ("se recomienda hacer..."). Mejor "te recomendamos...".
- Gerundios encadenados ("estando haciendo...").
- Doble negación ("no tengo nada").

**Preferir:**
- Verbos en presente y activo.
- Sujeto explícito (tú, Berto, nosotros).
- Oraciones cortas y concretas.

### Ejemplos de mejora

| Original | Mejor |
|---|---|
| "Es importante destacar que debes..." | "Recuerda..." |
| "Se recomienda realizar..." | "Te recomendamos..." |
| "Es necesario tener en cuenta que..." | "Considera que..." |
| "Podrías intentar hacer..." | "Puedes probar..." |
| "¿Estás experimentando ansiedad en este momento?" | "¿Sientes ansiedad ahora?" |

## Vocabulario

### Palabras prohibidas y sus reemplazos

| Prohibido | Reemplazo |
|---|---|
| adicto, drogadicto, drogadicto, alcohólico | persona que consume, persona con consumo problemático |
| recaída | consumió de nuevo, volvió a consumir |
| limpio / sucio (ref. a consumo) | sin consumo actualmente, en proceso |
| drogadicción, toxicomanía | consumo problemático, consumo de sustancias |
| ansioso (como insulto) | ansioso/a, con ansiedad, con tensión |
| enfermo, paciente | persona, quien esté pasando por... |
| tratamiento (sin matizar) | acompañamiento profesional, apoyo profesional |
| enfermo terminal | persona con enfermedad avanzada |
| demente, loco, psicópata | persona con..., persona que experimenta... |
| sufre de... | vive con..., experimenta... |
| víctima de... | persona que pasó por..., persona que vivió... |
| problema con... | patrón de... |

### Palabras preferidas

- **"craving" o "antojo intenso"** (no "deseo irrefrenable").
- **"espacio seguro"** (no "refugio", que connota evitación).
- **"proceso"** (no "lucha", "batalla", "guerra").
- **"cuidado"** (no "tratamiento", "cura").
- **"persona"** (no "individuo", "sujeto").
- **"consumo"** (no "uso de drogas" — "droga" tiene carga moral).
- **"acompañamiento"** (no "terapia" en primera mención; usar cuando el profesional es claro).

### Verbos preferidos

- **"puedes", "puedes intentar", "una opción es..."** (no "debes", "tienes que").
- **"explora", "comprueba", "observa"** (no "descubre", "entiende" — menos prescriptivos).
- **"registra", "anota"** (no "apunta" — coloquial excesivo).

## Inclusividad de género

### Regla general

Evitar masculino genérico. Preferir:

1. **Sustantivos neutros:** "persona", "equipo", "grupo", "quien".
2. **Formas dobles:** "todos y todas", "niños y niñas".
3. **Formas con "/a":** "listo/a", "cansado/a" (aceptado en español).
4. **Construcciones sin género:** "quien esté pasando por...", "si tienes...".
5. **Tuteo neutro:** "tú" (en sí mismo es neutro).

### Ejemplos

| Evitar | Preferir |
|---|---|
| "Adictos anónimos" | "Alcohólicos Anónimos" (es nombre propio) o "grupos de ayuda mutua" |
| "Bienvenido" | "Bienvenido/a", "Te damos la bienvenida" |
| "Todos los usuarios" | "Todas las personas usuarias", "Quien use la app" |
| "Si estás ansioso" | "Si sientes ansiedad" (sustantivo, no adjetivo) |
| "Los jóvenes" | "Las personas jóvenes", "La juventud" |
| "Está solo" | "Está en soledad", "Sin compañía" |

### Casos especiales

- Cuando uses "listo/a", asegúrate de que el resto del texto no use "el" o "la" que fuerce un género.
- En TTS, las formas con "/" se leen mal. Usa "listo o lista" o "listx" si la audiencia lo acepta.

## Estructura de mensajes

### Mensajes cortos (<50 caracteres)

Directos, sin contexto extra.

| Caso | Ejemplo |
|---|---|
| Botón principal | "Registrar mi día" |
| Acción | "Continuar" |
| Confirmación | "Listo" |

### Mensajes medianos (50-200 caracteres)

Una idea + acción concreta.

```
El craving sube como una ola. ¿Quieres que esperemos juntos los 15-20 minutos?
```

### Mensajes largos (>200 caracteres)

Párrafo corto + acción concreta + salida.

```
Entiendo. El craving es incómodo, pero suele pasar en 15-20 minutos si no lo
alimentas. Tenemos tres opciones: hablar con alguien de tu red, hacer un
ejercicio de respiración, o simplemente conversar mientras pasa.
```

### Títulos de pantalla

- **Máximo 4 palabras.**
- **Verbo en infinitivo o sustantivo.**
- **Sin artículos innecesarios.**

| Mal | Bien |
|---|---|
| "La guía de cómo manejar el craving" | "Manejo del craving" |
| "Información sobre el cristal" | "Cristal: información" |
| "Estoy en una situación de crisis" | "Estoy en crisis" |

## Tono por contexto

| Contexto | Tono |
|---|---|
| Onboarding | Cálido, invitador, esperanzador. |
| ASSIST resultados | Respetuoso, sin alarmar, sin etiquetar. |
| Crisis (Estoy en crisis, SOS) | Calmado, concreto, validante. Sin alarmas. |
| Craving | Comprensivo, sin moralizar. Invita a esperar la ola. |
| Berto chatbot | Cercano, entre pares. No paternal. |
| Insights | Observacional, sin diagnosticar. |
| Notificaciones | Breves, amables, sin demandar. |

## Listas y bullets

- **Bullet siempre en minúscula.**
- **Sin punto final** si el bullet no es oración completa.
- **Con punto final** si es oración completa.
- **Numerar** solo si el orden importa (instrucciones paso a paso).

## Botones

| Tipo | Patrón |
|---|---|
| Acción primaria | Verbo en infinitivo + objeto: "Registrar día", "Activar SOS". |
| Acción secundaria | "Volver", "Cancelar". |
| Confirmación | "Sí, ahora", "No, después". |

## Errores y validación

| Caso | Patrón |
|---|---|
| Campo vacío | "Necesitamos tu fecha de nacimiento." |
| Formato incorrecto | "El formato del teléfono no es válido." (sin "por favor"). |
| Sin permisos | "Para activar tu red de apoyo, necesitamos tu permiso de SMS." |
| Sin red | "Estás sin internet. Solvyx funciona completo. Solo Berto online y el directorio requieren red." |

## Internacionalización

- **Todas las strings del usuario** van en `strings.xml` para futura localización.
- **No hardcodear** en composables. Si una string nueva entra al código Kotlin, marcarla con un TODO para extracción.
- **Placeholders:** usar `%1$s`, `%1$d` para valores dinámicos.

```xml
<string name="bitacora_recordatorio">%1$s, ¿cómo te fue hoy?</string>
```

```kotlin
getString(R.string.bitacora_recordatorio, nombreUsuario)
```

## Pruebas de calidad de copy

Antes de mergear copy nuevo:

1. **Lee en voz alta.** Si suena forzado, rehazlo.
2. **Imagina el peor momento del usuario.** Si lo leería un joven en crisis, ¿ayuda o estorba?
3. **Pasalo por la skill `clinical-content-validation`** si es clínico.
4. **Pruebas de comprensión:** muestra el mensaje a 2-3 personas ajenas al proyecto. Si no entienden, simplifica.

## Anti-patrones prohibidos

1. **"Por favor" en exceso.** Una vez está bien; más suena condescendiente.
2. **"Te recomiendo encarecidamente..."** Pomposo. Solo di "te recomiendo..." o "considera...".
3. **"No dudes en contactarnos"** cliché corporativo.
4. **Errores de ortografía.** Detectarlos en code review.
5. **Textos sin espacios de género.** "listo" sin alternativa.
6. **Mayúsculas para énfasis.** "IMPORTANTE" o "¡AUXILIO!" está mal.
7. **Mezclar tú y usted en la misma pantalla.**
8. **Hardcodear strings en Composables** sin extraction a `strings.xml`.
